## 3. 문제를 만들 때 조심할 것

지금 문제 형식은 **한 문장에 틀린 곳이 한 군데**여야 하고, 띄어쓰기는 **두 가지가 모두 맞는 곳**이 있으면 안 됩니다. 2단계에는 여기에 걸리기 쉬운 것이 많습니다.

| 태그 | 조심할 것 |
|---|---|
| 되/돼 | '되어'로 바꿔 말이 되면 '돼'. 되요 → 돼요, 됬다 → 됐다, 안 되 → 안 돼 같은 확실한 것만. "되라/돼라"(명령 인용 등 둘 다 쓰이는 경우)는 피함 |
| 안/않 | **"않 했다 → 안 했다"는 띄어쓰기가 그대로라 됨.** 반대로 "안했다 → 안 했다"처럼 띄어쓰기까지 바뀌는 문장은 틀린 곳이 두 군데라 쓰지 않음. "하지 안았다"는 '안았다'(껴안다)가 따로 있는 말이라, 문장 뜻으로 확실히 '않았다'가 되게 씀 |
| 자주 틀리는 낱말 | 몇일 → 며칠, 금새 → 금세, 설겆이 → 설거지, 역활 → 역할, 일부로 → 일부러, 오랫만 → 오랜만, 희안하다 → 희한하다 등. 보기의 틀린 말 두 개 중 하나는 학생이 실제로 쓰는 틀린 말 |
| 뜻이 다른 낱말 | 잃어버리다/잊어버리다, 가르치다/가리키다, 낫다/낳다/낮다, 짓다/짖다, 바라다/바래다. **문장 안에서 뜻이 하나로만 읽히게** 씀(예: "숙제를 잃어버렸다"는 둘 다 말이 되어 쓰지 않음). '다르다/틀리다'는 뜻 구별 논쟁이 있어 넣지 않음 |
| 조사 붙여 쓰기 | 은/는/이/가/을/를/와/과/에/에서/도/만/에게/처럼. **'만큼, 대로, 뿐, 밖에'는 앞말에 따라 조사도 되고 의존 명사도 되어 넣지 않음** |
| 단위 띄어쓰기 | 한 개, 두 마리, 세 권, 다섯 명, 열 살처럼 **한글 수 + 단위**만. **'3학년, 2층, 5개'처럼 아라비아 숫자와 쓰거나 순서를 나타내면 붙여 써도 되어(제43항 다만) 넣지 않음** |

## 4. 개발 단위

## 6. 규칙 한 줄 초안 (M12 검수표로 옮김)

| 태그 | 규칙 한 줄(초안) |
|---|---|
| 되/돼 | '되어'로 바꿔 말이 되면 '돼', 말이 안 되면 '되'를 써요(돼요, 되고). |
| 안/않 | '아니'를 줄인 말은 '안', '아니하'를 줄인 말은 '않'이에요(안 먹어요, 먹지 않아요). |
| 자주 틀리는 낱말 | 자주 틀리는 낱말은 바른 모양을 기억해서 써요(며칠, 금세, 설거지). |
| 뜻이 다른 낱말 | 소리나 모양이 비슷해도 뜻이 다르면 알맞은 낱말을 골라 써요(잃어버리다/잊어버리다, 가르치다/가리키다). |
| 조사 붙여 쓰기 | '은, 는, 이, 가, 을, 를, 와, 과, 에, 도'처럼 낱말 뒤에 붙는 말은 앞말에 붙여 써요. |
| 단위 띄어쓰기 | '개, 마리, 권, 명'처럼 수를 세는 말은 앞의 수와 띄어 써요(사과 한 개). |

## 7. 확인 기준 (2단계 숲 완성)

- 단계 선택에서 2단계 숲이 "준비 중" 없이 열리고, 스테이지 3개를 차례로 깰 수 있다.
- 2단계 몬스터 6종이 그림으로 나오고 도감에 등록된다.
- 검수한 2단계 문제가 60개 이상이고, `npm run validate`가 통과한다.
- 4가지 화면 크기에서 2단계 문장 카드(25자)가 넘치지 않는다.
- 1단계·3단계 플레이(수치, 문제, 기록)는 바뀌지 않는다(기존 테스트 그대로 통과).
