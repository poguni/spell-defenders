# 문제 검수표 M12 (2단계 샘플 30문제)

> 작성일: 2026-10-11 · 문제 파일: `src/data/problems/level2-sample.json`

> 검수 기준: 표준국어대사전, 국립국어원 한국어 어문 규범(korean.go.kr)

## 구성

| 태그 | 문제 수 | 종류 |
|---|---|---|
| 되/돼 | 5 | 맞춤법 |
| 안/않 | 5 | 맞춤법(않 → 안 2, 안 → 않 3) |
| 자주 틀리는 낱말 | 5 | 맞춤법 |
| 뜻이 다른 낱말 | 5 | 맞춤법(가리키다/가르치다 2, 짖다, 낫다, 잊다) |
| 조사 붙여 쓰기 | 5 | 띄어쓰기 |
| 단위 띄어쓰기 | 5 | 띄어쓰기 |
| **합계** | **30** | |

- 2단계는 학생이 **틀린 낱말을 직접 찾아 누른 뒤** 보기 3개 중에서 고릅니다. 엉뚱한 낱말을 누르면 한 번 더 기회가 있습니다. "고칠 곳 없음" 문제는 없습니다(3단계만).
- 보기는 바른 말, 틀린 말 그대로, 헷갈릴 만한 다른 틀린 말 순서로 만들었고, 학생 화면에서는 섞입니다. **세 번째 보기에 사실은 맞는 말이 섞이지 않게** 했습니다(예: '되어요'는 맞는 말이라 넣지 않음).
- 단위 띄어쓰기는 아라비아 숫자를 쓰지 않고 한글 수만 썼습니다(아라비아 숫자와 쓰면 붙여 써도 되어서).
- 조사 붙여 쓰기에는 '만큼, 대로, 뿐, 밖에'를 넣지 않았습니다.

## 확신이 낮은 문제와 확인할 점

1. **2번 "그러면 안 되."**: 틀린 낱말이 "되." 한 글자라, 학생이 "안"을 누를 수도 있습니다(한 번 더 기회가 있음). 너무 어려우면 "그러면 안 되요."처럼 바꾸겠습니다.
2. **6번·8번 "안아요", "안았다"**: '안다'(껴안다)가 따로 있는 낱말이라 학생이 맞는 말로 생각할 수 있습니다. 문장 뜻으로는 '않다'만 맞습니다. 이런 문제를 넣어도 될지 봐 주세요.
3. **7번 보기 "않이"**, **9번 보기 "않은"**: 세 번째 보기를 만들기 어려워 문장에 넣으면 말이 안 되는 것으로 했습니다. '아니'는 "아니 했어요"처럼 맞는 말이 되어 넣지 않았습니다.
4. **20번 "약속을 깜빡 잃어버렸다."**: '깜빡'으로 '잊다'의 뜻이 되게 했습니다. "지갑을 잃어버렸다"처럼 두 뜻이 다 되는 문장은 넣지 않았습니다.
5. **29번 "스물다섯 명"**: '스물다섯'은 한 낱말(수사)로 붙여 썼습니다.
6. **안/않 근거**: '않' 문제는 표준국어대사전 '않다', '안' 문제는 '안'으로 적었습니다.
