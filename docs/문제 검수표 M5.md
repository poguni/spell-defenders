## 확신이 낮은 문제

1. **L3-deunji-007** "운동장에 가던지 말든지 빨리 정해." → '가든지': 한 문장에 틀린 '가던지'와 맞는 '말든지'가 함께 있어 헷갈릴 수 있습니다.
2. **L3-wen-006** "왠만하면 우리 같이 가자." → '웬만하면': '웬만하다'가 5학년에게 어려운 낱말인지 확인이 필요합니다.

4. **L3-uijon-008** "선생님이 말씀하신대로 줄을 섰다." → '말씀하신 대로': '말씀대로'(조사, 붙임)와 '말씀하신 대로'(의존 명사, 띄움)의 차이가 미묘합니다.
