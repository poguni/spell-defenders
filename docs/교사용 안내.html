1. 앱 한눈에 보기

  • 개인 수비전: 학생이 디벗으로 스테이지(오류 유형 3개씩 묶음)를 플레이합니다. 틀린 문제는 "낙서 지우기"로 다시 풀고, 오답 노트에 모입니다. 같은 유형을 3번 연속 맞히면 "익힘"이 됩니다.
  • 학급 수비전: 전자칠판에 몬스터가 한 마리씩 크게 나옵니다. 학생들이 답을 발표하면 선생님이 고릅니다. 학급 점수만 보여 주고 기록은 남기지 않습니다.
  • 교사 메뉴: AI로 문제를 만들어 승인하고, 문제 세트를 링크·QR·파일로 학생 기기에 나눠 줍니다.
  • 학생 기록은 학생 기기(브라우저)에만 저장됩니다. 로그인과 서버가 없고, 학생 개인정보를 모으지 않습니다.

3. 교과서 단원 ↔ 유형 태그 연결표 (5학년 2학기)

단원명은 선생님이 주신 목록(2026-10-11)입니다. 주요 학습 내용은 교과서를 보지 않고 단원명으로 짐작한 것이라 수업 전에 교과서로 확인해 주세요.
확신: 높음 단원 목표와 바로 이어짐 · 보통 단원 활동 안에서 쓸 수 있음 · 확인 필요 직접 연결이 약해 교과서를 보고 정해야 함
단원주요 학습 내용(단원명으로 본 짐작)연결 유형 태그추천 스테이지·활용확신
독서단원: 여러 가지 형태의 책을 읽어요.여러 형태의 책 읽기직접 연결 없음독서 감상문을 쓴 뒤 고쳐 쓰기 활동으로 스테이지 4(모두 섞기)확인 필요
1단원: 작품에 대한 의견을 나누어요.작품을 읽고 의견 말하기·쓰기직접 연결 없음의견 글을 쓴 뒤 고쳐 쓰기 활동으로 스테이지 4확인 필요
2단원: 올바른 문장으로 글을 써요.문장 성분의 호응, 바른 문장 쓰기, 고쳐 쓰기3단계 전체(로서/로써, 든지/던지, 맞히다/맞추다, 붙이다/부치다·반드시/반듯이, 웬/왠, 어떡해/어떻게, -이/-히, 사이시옷, 의존 명사 띄어쓰기)단원 정리에 스테이지 1~4, 학급 수비전으로 도입보통 (단원 중심이 문장 호응이면 맞춤법은 고쳐 쓰기 활동으로 연결. 앱에는 문장 호응 문제가 없음)

매체단원: 판단하며 이용해요.매체 자료를 판단하며 읽기직접 연결 없음매체 글 속 맞춤법 오류 찾기 활동 뒤 스테이지 4확인 필요

5단원: 추론하며 읽어요.생략된 내용 추론하며 읽기직접 연결 없음해당 없음(필요하면 정리 활동으로 스테이지 4)확인 필요
6단원: 작품을 감상해요.작품 감상하고 표현하기직접 연결 없음감상 글을 쓴 뒤 고쳐 쓰기 활동으로 스테이지 4확인 필요

  • 2단원에서 다루는 내용(예: 높임 표현, 시간 표현의 호응)을 알려 주시면, 그에 맞는 문제 유형을 추가할지 함께 정할 수 있습니다.

성취기준 확인 필요 항목

기획서 4.1에 적은 성취기준 번호와 문구는 자료마다 차이가 있었습니다. 국가교육과정정보센터(ncic.re.kr)의 2022 개정 국어과 고시 원문과 대조하지 않았습니다. 수업 계획서나 공문에 쓰기 전에 원문으로 확인해 주세요.

4. 수업 활용 예시

국어 단원 도입·정리 10분

  1. (2분) 전자칠판에 학급 수비전을 띄우고, 오늘 배울(또는 배운) 유형 하나만 켭니다. 몬스터는 5마리.
  2. (6분) 몬스터마다 모둠별로 답을 정해 발표하고, 선생님이 발표한 답을 고릅니다. 설명 창의 규칙을 함께 읽습니다.
  3. (2분) 학급 점수를 확인하고, 헷갈린 문장을 공책에 바르게 옮겨 씁니다.

창체 한 차시 (40분)

  1. (10분) 학급 수비전: 유형 2~3개, 몬스터 10마리. 규칙 설명을 함께 읽습니다.
  2. (20분) 개인 수비전: 디벗으로 스테이지를 하고, 끝나면 "낙서 지우기"로 틀린 문제를 다시 풉니다.
  3. (10분) 오답 노트 공유: 각자 오답 노트에서 가장 많이 틀린 유형을 하나 골라 짝에게 규칙을 설명합니다.
처음 쓰는 날에는 개인 수비전 전에 "느리게"와 "일시정지" 버튼, 몬스터를 누르면 그 몬스터가 멈춘다는 것을 먼저 보여 주세요.

2학년 활용 (1단계 마을, 10분)

  1. (3분) 전자칠판에 학급 수비전을 띄우고 1단계, 유형 하나, 몬스터 5마리를 고릅니다. 문장은 선생님이 소리 내어 읽어 주세요(앱에는 읽어 주기 기능이 없습니다).
  2. (5분) 개인 수비전 1단계 스테이지 1. 시작 전에 "느리게"와 "일시정지" 버튼을 먼저 보여 줍니다.
  3. (2분) 몬스터 도감에서 정화한 몬스터의 규칙 한 줄을 함께 읽습니다.

3~4학년 활용 (2단계 숲, 10분)

  1. (3분) 전자칠판에 학급 수비전을 띄우고 2단계, 유형 하나(예: 되/돼), 몬스터 5마리를 고릅니다. 틀린 낱말이 어디인지 먼저 손을 들어 찾게 한 뒤 보기를 고릅니다.
  2. (5분) 개인 수비전 2단계에서 같은 유형이 들어간 스테이지를 합니다.
  3. (2분) 오답 노트에서 규칙 카드를 함께 읽고, 틀린 문장을 공책에 바르게 옮겨 씁니다.

5. OpenRouter API 키 (AI로 문제를 만들 때만)

AI 문제 만들기는 선택 기능입니다. 내장 문제만으로도 앱을 쓸 수 있습니다.

  1. https://openrouter.ai 에 가입하고 크레딧을 충전합니다.
  2. Keys 메뉴에서 이 앱 전용 키를 만들고 Credit limit(사용 한도)를 꼭 걸어 둡니다(예: 5달러).
  3. 앱 시작 화면 → 교사 메뉴 → PIN 입력 → API 키·모델 설정에서 키를 붙여 넣고 키 저장을 누릅니다.
    • 기본은 이번 접속에서만 기억하고, 브라우저를 닫으면 지워집니다.
    • 교사 개인 기기라면 "이 기기에 저장"을 골라도 됩니다. 공용 기기에서는 고르지 마세요.
  4. 연결 확인으로 키와 남은 한도를 확인합니다(문제를 만들지 않아 비용이 들지 않습니다).
  5. 다 쓰면 키 지우기를 누릅니다.
  • 키는 OpenRouter(openrouter.ai)로만 보내고, 앱 코드·저장소·학생 기기에는 들어가지 않습니다.
  • 모델: Claude Sonnet 5.5(기본, 품질 우선), Gemini 3.8 Flash(균형), GPT-6 Luna(비용 최소). 문제 20개 1회에 약 3~60원입니다.
  • 교사 메뉴 PIN은 학생이 실수로 들어오는 것을 막는 정도의 장치입니다. PIN을 잊으면 "PIN을 잊었어요"로 교사 메뉴를 초기화합니다(PIN, 저장한 키, 문제 세트가 지워집니다).

6. AI로 문제 만들고 승인하기

  1. 교사 메뉴 → AI로 문제 만들기: 단계, 유형(하나), 개수(5~20), 소재(선택)를 고르고 만들기.
  2. 앱이 형식을 자동으로 검사합니다. 틀린 곳이 문장에 없거나 보기에 정답이 없는 문제 등은 이유와 함께 빠집니다.
  3. 통과한 문제를 세트에 저장하고, 승인 화면에서 하나씩 확인합니다.
    • 승인: 맞으면 승인합니다. 승인한 문제만 학생에게 나옵니다.
    • 수정: 문장·정답·보기·설명을 고치면 다시 검사하고 승인됩니다.
    • 삭제: 쓰지 않을 문제를 지웁니다.
  4. 교사 메뉴의 세트마다 출제 켜짐/꺼짐이 있습니다. 켜진 세트의 승인한 문제는 이 기기의 스테이지와 학급 수비전에 내장 문제와 섞여 나옵니다.
AI가 만든 문장도 정답이 틀릴 수 있습니다. 표준국어대사전과 한글 맞춤법으로 꼭 확인한 뒤 승인해 주세요.

7. 문제 세트 나눠 주기 (공유 링크·QR·파일)

교사 메뉴 → 세트의 나눠 주기를 누릅니다. 승인한 문제만 보내지고, API 키와 학생 기록은 보내지 않습니다.

승인한 문제 수나눠 주는 방법
약 5개 이하QR이 나옵니다. 전자칠판에 띄우고 학생이 칠판 가까이 와서 디벗 카메라로 찍습니다(문제가 많을수록 QR이 촘촘해져 멀리서는 잘 찍히지 않습니다).
30개 이하링크 복사 → 학급 게시판, 클래스룸, 메신저 등에 올립니다. 학생은 링크를 엽니다.
30개 초과파일로 내보내기 → 파일을 학생 기기로 옮긴 뒤 시작 화면의 문제 파일 불러오기로 엽니다.

학생 쪽:

  1. 링크(또는 QR)를 열면 세트 이름과 문제 수가 나옵니다. 불러오고 바로 하기를 누르면 바로 한 판이 시작됩니다.
  2. 지도에 선생님 문제 스테이지가 생겨 다시 할 수 있습니다. 별과 오답 노트도 평소처럼 남습니다.
  3. 새 세트를 불러오면 이전 세트는 바뀝니다(한 번에 한 세트).
  • 링크 속 문제 정보는 주소의 # 뒤에 있어 서버로 보내지지 않습니다.
  • 받는 기기가 문제를 다시 검사하고, 망가졌거나 조작된 링크·파일은 받지 않습니다.

8. 학생 기기 참고

  • 기록(별, 오답 노트, 도감, 닉네임)은 그 기기의 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 함께 지워집니다.
  • 학생 기기에는 API 키가 필요 없습니다.

학생 기록 지키기 (내 기록)

처음 화면 아래 "내 기록" 버튼을 누르면 성적표와 기록 관리 버튼이 있습니다.

버튼하는 일
성적표단계별 스테이지 별, 익힌 유형(같은 유형 3번 연속 정답), 몬스터 도감, 오답 노트 수를 한 화면에 보여 줍니다. 날짜가 함께 나와 화면 캡처로 제출하기 좋습니다
내 기록 저장하기기록을 파일(맞춤법수비대-기록-닉네임-날짜.json)로 디벗의 '다운로드' 폴더에 저장합니다
내 기록 불러오기저장한 파일을 고르면 "지금 기록 / 파일 기록"을 나란히 보여 주고, 확인하면 파일 기록으로 바꿉니다(합치지 않고 통째로 바꿈)
내 기록 지우기"저장하고 지우기"(파일을 남기고 지움), "지우기"(되살릴 수 없음), "그만두기" 중에서 고릅니다

언제 저장하게 할지 (권장)

  • 파일럿 동안은 주 1회(예: 금요일 마지막 활동 뒤) "내 기록 저장하기"를 함께 누릅니다.
  • 공용 디벗은 매 시간 끝에 "내 기록 지우기 → 저장하고 지우기", 다음 시간 시작에 "내 기록 불러오기"를 합니다.
  • 디벗을 초기화하거나 바꾸기 전에는 꼭 저장합니다.

파일을 어디에 둘지

  • '다운로드' 폴더는 디벗 정리 때 지워질 수 있습니다. 학생 구글 드라이브(또는 학급 공유 폴더)로 옮겨 두면 안전합니다.
  • 다른 디벗에서 불러올 때는 드라이브에서 파일을 내려받은 뒤 "내 기록 불러오기"로 고릅니다.

파일에 들어 있는 것

  • 닉네임(선택), 마지막으로 고른 단계, 스테이지별 별, 오답 노트, 유형별 연속 정답, 도감, 소리 설정뿐입니다. 이름·학번 같은 개인정보는 앱이 모르므로 들어가지 않습니다.
  • 교사 메뉴 데이터(PIN, API 키, 문제 세트)와 불러온 선생님 문제 세트는 들어가지 않습니다. 선생님 문제는 링크로 다시 받으면 별이 이어집니다.
  • 다른 파일(문제 세트 파일, 망가진 파일)을 고르면 지금 기록은 그대로 두고 안내 문구만 나옵니다.

9. 사전·사후 간이 평가지 (파일럿용, 각 20문항)

  • 검수한 3단계 문제에서 골랐습니다. 사전과 사후는 같은 문장이 없고, 유형마다 2문항씩(18문항) + "고칠 곳 없음" 2문항으로 구성이 같습니다.
