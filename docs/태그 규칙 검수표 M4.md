# 태그 규칙 검수표 M4 (3단계 9개 태그)

> 작성일: 2026-10-10 · 내용 파일: `src/data/tagInfo.ts`
> 오답 노트의 "규칙 설명 카드"와 몬스터 도감 카드에 나오는 한 줄 규칙입니다. 문제의 explain(문제마다 설명)과 달리, 태그 하나에 하나씩 있습니다.
> 2026-10-10 선생님 검수 완료: 규칙 설명 9개와 새 몬스터 이름 3개 모두 그대로 사용.

| 번호 | 태그 | 몬스터 이름 | 규칙 설명 | 확인할 점 |
|---|---|---|---|---|
| 1 | 로서/로써 | 갈림길 거북 | '~이 되어서(자격)'라는 뜻이면 '로서', '~을 가지고(방법·도구·재료)'라는 뜻이면 '로써'를 써요. | |
| 2 | 든지/던지 | 되돌이 달팽이 (새 이름) | 여럿 가운데 고를 때는 '든지', 지난 일을 떠올릴 때는 '던지'를 써요. | 몬스터 이름 |
| 3 | 맞히다/맞추다 | 과녁 두더지 | 답을 틀리지 않게 하거나 목표에 닿게 하면 '맞히다', 서로 비교하거나 제자리에 맞게 붙이면 '맞추다'예요. | |
| 4 | 붙이다/부치다, 반드시/반듯이 | 우표 문어 | 딱 대어 떨어지지 않게 하면 '붙이다', 편지를 보내거나 전을 익히면 '부치다'예요. '꼭'이라는 뜻은 '반드시', 비뚤지 않다는 뜻은 '반듯이'예요. | 두 쌍을 한 카드에 담아 문장이 깁니다 |
| 5 | 웬/왠 | 물음표 박쥐 | '왜인지'를 줄인 '왠지'에만 '왠'을 써요. '웬일', '웬 상자'처럼 나머지는 모두 '웬'이에요. | |
| 6 | 어떡해/어떻게 | 얼룩 카멜레온 (새 이름) | '어떻게 해'를 줄인 말은 '어떡해', 방법이나 모양을 물을 때는 '어떻게'를 써요. | 몬스터 이름 |
| 7 | -이/-히 | 꼬리표 다람쥐 (새 이름) | 끝소리가 '이'로만 나면 '이'(깨끗이, 번번이), '히'로도 나면 '히'(꼼꼼히)로 써요. | **확신 낮음**: 제51항은 "'이'로만 나는 것은 '이', '히'로만 나거나 '이·히'로 나는 것은 '히'"입니다. 아이용으로 줄이면서 정확한지 확인 필요. 몬스터 이름 |
| 8 | 사이시옷 | 사이 거미 | 두 낱말이 만나 뒷말 첫소리가 된소리로 나거나 'ㄴ' 소리가 덧나면 사이시옷을 넣어요(바닷가, 나뭇잎). | **확신 낮음**: 제30항의 조건 "둘 중 하나는 고유어", "앞말이 모음으로 끝남"을 뺐습니다. 이대로 둘지 확인 필요 |
| 9 | 의존 명사 띄어쓰기 | 찰싹 애벌레 | '수, 것, 지, 만큼'처럼 혼자 쓰이지 못하는 낱말(의존 명사)도 앞말과 띄어 써요. | |

- 새 이름 세 개(되돌이 달팽이, 얼룩 카멜레온, 꼬리표 다람쥐)는 그림을 만들 때 바꿔도 됩니다. 기획서 16.3 표에 함께 적었습니다.
- 보조 용언 태그는 아직 문제가 없어 도감에 나오지 않습니다.
