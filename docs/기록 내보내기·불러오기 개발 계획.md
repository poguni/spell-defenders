# 기록 내보내기·불러오기 개발 계획

> 작성일: 2026-10-12 · 기준: 기획서 6.2("기록 내보내기: 학생이 자기 기록을 파일로 저장하거나 화면 캡처용 성적표 보기"), 11장(개인정보), 13장("서버 없음 → 기록 유실" 대응)
> 지금까지처럼 작은 단위(M15 → M16) 하나씩 진행하고, 단위마다 실행 가능한 상태와 진행 기록을 남깁니다.

---

## 1. 목표

학생 디벗의 브라우저에만 있는 게임 기록을 **파일 하나로 저장했다가 다시 넣을 수 있게** 해서, 파일럿(2~3주) 동안 기록이 사라지는 일을 막습니다. 자기 기록을 한눈에 보는 **성적표**도 함께 만듭니다.

| 상황 | 지금 | 만든 뒤 |
|---|---|---|
| 브라우저 데이터 삭제, 디벗 초기화 | 기록이 사라짐 | 저장해 둔 파일로 되살림 |
| 다른 디벗을 쓰게 됨 | 처음부터 다시 | 파일로 옮김 |
| 공용 디벗을 여러 학생이 번갈아 씀 | "내 기록 지우기"를 하면 영영 사라짐 | 지우기 전에 저장, 다음 시간에 불러오기 |
| 선생님께 내 기록 보여 주기 | 지도·도감을 하나씩 보여 줌 | 성적표 한 화면 |

## 2. 지금 상태

| 구분 | 상태 |
|---|---|
| 학생 기록 | `src/storage/save.ts`, localStorage `spell-defenders`. `version`(1), `nickname`, `level`, `stars`, `tagStreaks`, `wrongNotes`, `dex`, `soundOn` |
| 옛 버전 기록 | `MIGRATIONS`로 차례로 바꾸는 틀이 있음(지금은 비어 있음) |
| 기록 읽기 | `parseSave`: 깨졌거나 앱보다 새 버전이면 **빈 기록**을 돌려줌(앱이 멈추지 않게). 파일 불러오기에는 그대로 쓸 수 없음 → "실패"를 알려 주는 엄격한 읽기가 따로 필요 |
| 파일 저장 | `ShareScreen.tsx`에 문제 세트를 `.json`으로 내려받는 코드(Blob + 링크)가 있음 |
| 파일 고르기 | `StartScreen.tsx`의 "문제 파일 불러오기"(파일 입력)가 있음 |
| 기록 지우기 | 시작 화면 아래 "내 기록 지우기" → 확인 창(지우기/그만두기) |

## 3. 정해야 할 것 (추천안)

| 질문 | 추천 | 이유 |
|---|---|---|
| 버튼 위치 | 시작 화면 아래 줄의 "내 기록 지우기"를 **"내 기록"** 버튼으로 바꾸고, 새 **내 기록 화면**에 성적표·저장하기·불러오기·지우기를 모음 | 아래 줄에 버튼이 5개가 되면 복잡함. 기록에 관한 것을 한곳에 모으면 학생이 찾기 쉬움 |
| 불러올 때 | 지금 기록을 **통째로 바꿈**. 바꾸기 전에 두 기록(지금 / 파일)의 요약을 나란히 보여 주고 확인 | 합치기는 오답 노트·연속 정답을 어떻게 합칠지 애매하고, 학생이 결과를 예상하기 어려움 |
| 지우기 전에 | 확인 창에 **"저장하고 지우기"** 버튼을 더함(지우기 / 저장하고 지우기 / 그만두기) | 공용 디벗에서 실수로 기록을 잃는 일을 줄임 |
| 파일 이름 | `맞춤법수비대-기록-닉네임-2026-10-12.json`(닉네임이 없으면 빼고, 파일 이름에 못 쓰는 글자는 뺌) | 다운로드 폴더에 여러 학생 파일이 섞여도 구별됨 |
| 담을 것 | 학생 기록 전체(소리 설정 포함). 교사 메뉴(PIN, API 키, 문제 세트)와 불러온 "선생님 문제" 세트는 **담지 않음** | 학생 파일에 교사 정보가 섞이면 안 됨. 선생님 문제는 링크로 다시 받으면 됨(별은 기록에 남아 있어서 같은 세트를 다시 받으면 이어짐) |
| 성적표 | M16에서 내 기록 화면 위쪽에 | 저장·불러오기를 먼저 확실히 만들고, 화면 꾸미기는 다음 단위로 |
| 선생님이 반 전체 기록 모으기 | **이번에는 만들지 않음** | 기획서에 없고 범위가 큼. 파일럿에서 필요하면 따로 계획 |

## 4. 파일 형식

```json
{
  "format": "spell-defenders-record",
  "exportedAt": "2026-10-12T09:30:00.000Z",
  "save": { "version": 1, "nickname": "민준", "level": 3, "stars": { "L3-1": 3 }, "...": "..." }
}
```

- `save`는 localStorage에 저장하는 것과 같은 모양입니다. 앱이 업데이트되어 기록 형식(`version`)이 바뀌어도, 옛 파일은 `MIGRATIONS`로 바꿔서 불러옵니다.
- **거부하는 파일** (지금 기록은 그대로 두고 쉬운 말로 안내)
  - JSON이 아니거나 `format`이 다름(예: 문제 세트 파일) → "맞춤법 수비대 기록 파일이 아니에요."
  - 앱보다 새 버전 → "더 새로운 앱에서 저장한 기록이에요. 화면을 새로 고친 뒤 다시 불러와 주세요."
  - 너무 큰 파일(1MB 넘음), 필수 칸이 없음
- 일부 칸만 이상하면(예: 별 숫자가 음수) 그 칸만 기본값으로 채웁니다. 지금 `parseSave`의 규칙과 같습니다.

## 5. 개발 단위

### M15. 내 기록 화면, 저장하기·불러오기

| 할 일 | 내용 |
|---|---|
| 파일 만들기·읽기 | `src/storage/recordFile.ts`(새 파일): `exportRecord(save)` → 파일 내용, `importRecord(text)` → 기록 또는 실패 이유. `save.ts`에 실패를 알려 주는 엄격한 읽기를 더하고 `parseSave`와 칸별 규칙을 함께 씀 |
| 내 기록 화면 | `src/screens/RecordScreen.tsx`(새 파일): 지금 기록 요약 한 줄(닉네임, 별 수, 도감 수, 오답 노트 수), "내 기록 저장하기", "내 기록 불러오기", "내 기록 지우기", "처음으로" |
| 불러오기 확인 | 파일을 고르면 "지금 기록 / 파일 기록" 요약을 나란히 보여 주고 "이 기록으로 바꾸기" / "그만두기" |
| 지우기 확인 | 지우기 / 저장하고 지우기 / 그만두기 |
| 시작 화면 | 아래 줄의 "내 기록 지우기" → "내 기록" |
| 파일 내려받기 코드 | `ShareScreen.tsx`와 같은 방식을 함께 쓰도록 작은 함수로 묶음 |
| 확인 | 단위 테스트(왕복, 옛 버전, 새 버전 거부, 문제 세트 파일 거부, 망가진 파일, 큰 파일, 파일 이름), 화면 테스트(플레이 → 저장 → 지우기 → 불러오기 → 별·오답 노트·도감 그대로, 저장하고 지우기, 잘못된 파일 거부), 4가지 화면 크기 |

**선생님이 할 일**: 학생 디벗(크롬북)에서 저장한 파일이 '다운로드' 폴더에 생기는지, 그 파일을 다른 디벗에서 불러올 수 있는지 확인(USB나 구글 드라이브로 옮겨 보기)

### M16. 성적표, 교사용 안내

| 할 일 | 내용 |
|---|---|
| 성적표 | 내 기록 화면 위쪽: 닉네임, 오늘 날짜, 단계별 별(스테이지마다), 익힌 유형 목록, 도감 n / 전체, 오답 노트에 남은 문제 수. 화면 캡처 한 장에 다 들어오게(1920×1080, 1366×650) |
| 교사용 안내 | "학생 기록 지키기" 장: 언제 저장하게 할지(예: 주 1회, 공용 디벗은 매 시간 끝), 파일을 어디에 둘지(학교 구글 드라이브 등), 불러오는 방법, 기록 파일에 들어 있는 것(개인정보는 닉네임뿐) |
| 첫 학교 테스트 안내 | 공용 디벗 안내를 "저장하고 지우기"로 바꿈 |
| 확인 | 화면 테스트(성적표 숫자가 지도·도감과 같은지, 캡처 크기), 스크린숏 |

## 6. 개인정보와 안전

- 파일에는 **닉네임(선택)과 게임 기록만** 들어갑니다. 이름·학번 같은 정보는 앱이 모르므로 들어가지 않습니다.
- 파일은 학생 기기에서 만들어져 학생 기기에 저장됩니다. 어디로도 보내지 않습니다(서버 없음).
- 불러온 파일은 글자로만 읽고 실행하지 않습니다. 크기 상한과 칸별 검사를 거칩니다.
- 교사 메뉴 데이터(PIN 해시, API 키, 문제 세트)는 파일에 담지 않습니다.

## 7. 확인 기준 (완성)

- 학생 디벗에서 기록을 파일로 저장하고, 기록을 지운 뒤(또는 다른 디벗에서) 그 파일을 불러오면 별·오답 노트·익힘 진행·도감이 그대로 돌아온다.
- 문제 세트 파일, 망가진 파일, 새 버전 파일은 지금 기록을 바꾸지 않고 쉬운 말로 거부한다.
- "내 기록 지우기"에서 "저장하고 지우기"를 고를 수 있다.
- 성적표가 화면 한 장에 들어오고, 숫자가 지도·도감과 같다.
- 기존 플레이·학급 수비전·교사 메뉴·문제 세트 불러오기는 바뀌지 않는다(기존 테스트 그대로 통과).
