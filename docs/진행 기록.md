## M1. 프로젝트 생성과 16:9 화면 틀 — 2026-10-10

**한 일**
- React 18.3 + Vite 6.4 + TypeScript 5.9 프로젝트를 직접 구성(Vite 기본 템플릿은 React 19라서 쓰지 않음), git 저장소 초기화
- 테스트 도구: Vitest 5.0.3(처음 설치한 3.2에 보안 권고가 있어 올림, `npm audit` 0건), Playwright 1.64(컴퓨터에 설치된 Chrome 사용)
- 기획서 10.2 폴더 구조 생성(빈 폴더는 `.gitkeep`)
- 16:9 무대: `src/components/Stage.tsx`, 비율 계산 `src/components/stageFit.ts`. 1920×1080 좌표로 배치하고 창 크기에 맞춰 통째로 확대·축소, 남는 곳은 어두운 여백
- 시작 화면 `src/screens/StartScreen.tsx`: 제목, 시작하기, 전체 화면 버튼(지원하지 않는 브라우저에서는 숨김)
- 수비전 임시 배치 `src/screens/BattleScreen.tsx`: 레인 3줄, 임시 몬스터 3마리와 말풍선, 성문, 수비대원 자리, 위쪽 정보 막대(성벽 체력, 웨이브, 마나, 속도 버튼), 아래쪽 문장 카드(보기 버튼 3개, 동작 없음)
- 임시 그림은 모두 `src/components/PlaceholderArt.tsx` 한 곳에 모음(M5에서 이 파일만 바꾸면 됨)
- 글꼴: Pretendard(npm 패키지, 필요한 글자 조각만 내려받는 dynamic subset)
- 크기 기준: 무대 좌표로 문장 카드 56px·보기 44px, 버튼 높이 80~110px. 1366×650에서도 문장 카드 글자 실제 약 34px, 버튼 실제 48px 이상

**확인 결과**
- `npm test`: 5개 통과(무대 비율 계산)
- `npm run build`: 통과
- `npm run test:e2e`: 4개 통과. 1920×1080, 1536×864, 1366×768, 1366×650(주소창 때문에 실제 보이는 크기)에서
  - 시작 화면·수비전 요소가 무대 밖으로 나가지 않음
  - 버튼 실제 크기 48px 이상, 문장 카드 글자 실제 24px 이상, 문장이 카드 밖으로 넘치지 않음
- 스크린숏: `docs/screenshots/M1/` (start-*, battle-* 각 4장)

**남은 일·알려진 문제**
- 몬스터 말풍선 글자는 1366×650에서 실제 약 18px로 작다. 말풍선은 미리보기이고 문제는 문장 카드에서 읽으므로 M3에서 말풍선을 짧게 할지 함께 정한다.
- 수비전에서 시작 화면으로 돌아가는 버튼은 아직 없다(새로고침으로 돌아감). M3 결과 화면·M4 지도와 함께 만든다.
- 실제 디벗 기기에서는 아직 확인하지 않았다(배포 뒤 M5에서 확인).

**다음 단계(M2)에서 먼저 볼 파일**
- `docs/맞춤법 수비대 단계별 프롬프트.md` M2, 기획서 4장·7.4·8장·9장
- 판정 로직은 `src/judge/`, 검증 스크립트는 `scripts/validate-problems.ts`에 만든다(아직 빈 폴더)

**실행 방법**
- 개발 서버: `npm run dev` → 브라우저에서 http://localhost:5173
- 테스트: `npm test`, 화면 검사: `npm run test:e2e`
