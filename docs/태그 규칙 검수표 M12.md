# 태그 규칙 검수표 M12 (2단계 6개 태그)

> 작성일: 2026-10-11 · 내용 파일: `src/data/tagInfo.ts`
> 오답 노트의 "규칙 설명 카드"와 몬스터 도감 카드에 나오는 한 줄 규칙과 몬스터 이름입니다. 3~4학년이 읽는다고 보고 썼습니다.

| 번호 | 태그 | 몬스터 이름 | 규칙 설명 | 확인할 점 |
|---|---|---|---|---|
| 1 | 되/돼 | 둔갑 여우 | '되어'로 바꿔 말이 되면 '돼', 말이 안 되면 '되'를 써요(돼요, 되고). | |
| 2 | 안/않 | 도리도리 고슴도치 | '아니'를 줄인 말은 '안', '아니하'를 줄인 말은 '않'이에요(안 먹어요, 먹지 않아요). | |
| 3 | 자주 틀리는 낱말 | 뒤죽박죽 부엉이 | 자주 틀리는 낱말은 바른 모양을 기억해서 써요(며칠, 금세, 설거지). | 규칙이라기보다 "기억하기"라서, 예를 바꾸고 싶으면 알려 주세요 |
| 4 | 뜻이 다른 낱말 | 짝짝이 나비 | 소리나 모양이 비슷해도 뜻이 다르면 알맞은 낱말을 골라 써요(잃어버리다/잊어버리다, 가르치다/가리키다). | 카드에 들어가기에 조금 깁니다 |
| 5 | 조사 붙여 쓰기 | 업어 개구리 | '은, 는, 이, 가, 을, 를, 와, 과, 에, 도'처럼 낱말 뒤에 붙는 말은 앞말에 붙여 써요. | "조사"라는 말은 쓰지 않았습니다 |
| 6 | 단위 띄어쓰기 | 도토리 곰 | '개, 마리, 권, 명'처럼 수를 세는 말은 앞의 수와 띄어 써요(사과 한 개). | 아라비아 숫자와 쓰면 붙여 써도 된다는 것은 넣지 않았습니다 |

- 몬스터 이름과 그림은 `docs/2단계 숲 개발 계획.md` 5장, `docs/몬스터 그림 프롬프트 (2단계).md`를 따랐습니다. 그림 12장은 들어와 있고 M13에서 연결합니다.
