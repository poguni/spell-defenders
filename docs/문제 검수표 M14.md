# 문제 검수표 M14 (2단계 추가 30문제)

> 작성일: 2026-10-11 · 문제 파일: `src/data/problems/level2-batch2.json`
> 모두 `"reviewed": false`입니다. 검수가 끝나면 알려 주세요. `true`로 바꾸면 2단계가 태그마다 10문제(모두 60문제)가 됩니다.
> 검수 기준: 표준국어대사전, 국립국어원 한국어 어문 규범(korean.go.kr). 만든 방식은 `docs/문제 검수표 M12.md`와 같습니다.

## 구성

| 태그 | 문제 수 | 종류 |
|---|---|---|
| 되/돼 | 5 | 맞춤법(되 → 돼 4, 돼 → 되 1) |
| 안/않 | 5 | 맞춤법(안 → 않 3, 않 → 안 2) |
| 자주 틀리는 낱말 | 5 | 맞춤법(역할, 희한하다, 어이없다, 설렘, 거) |
| 뜻이 다른 낱말 | 5 | 맞춤법(짓다, 낳다, 바라다, 낮다, 닫히다) |
| 조사 붙여 쓰기 | 5 | 띄어쓰기 |
| 단위 띄어쓰기 | 5 | 띄어쓰기(자루, 컵, 마리, 살, 송이) |
| **합계** | **30** | |

- 샘플 30문제와 같은 문장은 없습니다.
- 처음 만든 "소풍 날 설레임이…"는 '소풍날'을 붙여 쓸지 확실하지 않아 "내 마음은 설레임으로 가득했다."로 바꿨습니다.

## 확신이 낮은 문제와 확인할 점

1. **15번 "내 꺼야 → 내 거야"**: 소리 때문에 틀리는 말이라 1단계 '된소리'에 가깝기도 합니다. 자주 틀리는 말이라 2단계 '자주 틀리는 낱말'에 넣었습니다.
2. **18번 "바래요 → 바라요"**: 표준어는 '바라요'지만 일상에서 '바래요'를 많이 써서, 학생이 '바라요'를 어색하게 느낄 수 있습니다. 설명으로 짚어 주는 데 의미가 있다고 보고 넣었습니다.
3. **20번 "문이 바람에 다쳤다 → 닫혔다"**: 세 번째 보기를 '닫쳤다'로 하지 않았습니다. '닫치다'(세게 닫다)가 따로 있는 말이라서입니다.
4. **27번 "물 한 컵"**: '컵'은 그릇 이름이지만 수량을 셀 때도 앞말과 띄어 씁니다.
5. **25번 "할머니께"**: 높임의 '께'도 조사라 붙여 씁니다. 3~4학년에게 '께'가 익숙한지 봐 주세요.
