# 문제 검수표 M9 (1단계 샘플 30문제)

> 검수 기준: 표준국어대사전, 국립국어원 한국어 어문 규범(korean.go.kr)

- 1단계는 보기가 **2개**(바른 말, 틀린 말)입니다. 학생 화면에서는 보기 순서가 섞입니다.
- 1단계는 틀린 곳이 처음부터 표시됩니다. 문장 부호 문제는 틀린 부호 자리가 빈칸으로 나옵니다.
- 문장은 모두 15자 이하이고(띄어쓰기·부호 포함), 한 문장에 틀린 곳이 한 군데입니다.
- 된소리는 띄어쓰기까지 바뀌는 "할꺼야 → 할 거야"를 빼고, 띄어쓰기가 그대로인 -ㄹ게, -ㄹ걸, -ㄹ지, -ㄹ수록만 넣었습니다.
- 느낌표 문제는 틀린 문장에 마침표 대신 물음표를 썼습니다. 감탄문은 마침표도 허용되는 경우가 있어서입니다.

## 확신이 낮은 문제와 확인할 점

1. **소리 나는 대로 쓰기와 받침의 경계**: 4번(오슬 → 옷을), 5번(머거요 → 먹어요)은 받침이 뒤로 넘어가 소리 나는 경우라 '받침' 태그로 볼 수도 있습니다. 지금은 "소리 나는 대로 이어 쓴 것"을 '소리 나는 대로 쓰기'로, "받침 글자 자체를 틀린 것"(닥, 부억, 박, 햇빗)을 '받침'으로 나눴습니다. 9번(안자요 → 앉아요)은 둘 다에 걸쳐 있어 '받침'에 두었습니다. 이렇게 나누는 것이 괜찮은지 봐 주세요.
2. **4번·5번의 근거**: 제14항(체언과 조사 구별), 제15항(어간과 어미 구별)으로 적었습니다. 1·2·3번은 제6항(구개음화)입니다.
3. **받침·ㅐ/ㅔ 근거**: 낱말 표기 문제라 근거를 표준국어대사전 낱말로 적었습니다.
4. **18번 "가져올걸"**: 아쉬움을 나타내는 '-ㄹ걸'이 2학년에게 익숙한지 확인이 필요합니다. 어려우면 다른 문장으로 바꾸겠습니다.
5. **띄어쓰기 기초 설명**: 5문제 모두 "낱말과 낱말 사이를 띄어 써요."로 같습니다. 문제마다 다르게 쓰는 것이 좋으면 알려 주세요.
