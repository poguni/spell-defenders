## 2. 2학년을 위해 달라져야 할 것

1. **읽는 속도**: 2학년은 문장을 읽는 데 시간이 더 걸립니다. 몬스터를 더 느리게 하고 한 판을 더 짧게 합니다.
2. **보기 2개**: 기획서 7.4대로 맞춤법 보기를 2개로 줄입니다(바른 말 1 + 틀린 말 1).
3. **더 큰 글자**: 1단계 문장은 15자 이하라 카드에 여유가 있습니다. 문장·보기 글자를 키웁니다.
4. **쉬운 말**: 설명(`explain`)과 규칙 한 줄을 2학년 낱말로, 짧게 씁니다. 화면 안내 문구도 1단계에서는 더 짧게 씁니다.
5. **낱말 수준**: 2학년 교과서·생활에서 쓰는 낱말만 씁니다.

## 4. 문제를 만들 때 조심할 것

현재 문제 형식은 **한 문장에 틀린 곳이 한 군데**여야 합니다(자동 검증 규칙). 1단계 예시 가운데 이 규칙에 걸리는 것이 있습니다.

| 태그 | 조심할 것 |
|---|---|
| 소리 나는 대로 쓰기 | 틀린 부분은 어절 하나(가치 → 같이, 구지 → 굳이). 사투리·발음 차이가 큰 낱말은 피함 |
| 받침 | 닥 → 닭, 일따 → 읽다. 겹받침은 2학년이 자주 쓰는 낱말만(닭, 읽다, 앉다, 많다) |
| ㅐ/ㅔ | 배개 → 베개, 께끗이 → 깨끗이. 둘 다 있는 낱말(개/게, 새/세)은 뜻이 분명한 문장에서만 |
| 된소리 | **"할꺼야 → 할 거야"는 띄어쓰기까지 바뀌어 틀린 곳이 두 군데라 쓰지 않음.** 할께 → 할게, 할껄 → 할걸, 할찌 → 할지, 갈쑤록 → 갈수록처럼 띄어쓰기가 그대로인 것만 |
| 문장 부호 | 문장 끝 부호만. 묻는 문장(?)과 설명하는 문장(.) 중심, 느낌표는 "우아", "와" 같은 감탄 낱말이 있는 문장만 |
| 띄어쓰기 기초 | 낱말 3~4개, 15자 이하. 의존 명사("할 수"), 보조 용언("먹어 보다"), 붙여 써도 되는 합성어는 넣지 않음 |

## 7. 규칙 한 줄 초안 (M9 검수표로 옮김)

| 태그 | 규칙 한 줄(초안) |
|---|---|
| 소리 나는 대로 쓰기 | 소리 나는 대로 쓰지 않고, 낱말의 원래 모양을 살려 써요(같이, 굳이). |
| 받침 | 소리가 잘 안 들려도 받침을 빠뜨리지 않고 써요(닭, 읽다). |
| ㅐ/ㅔ | 소리가 비슷한 ㅐ와 ㅔ는 낱말마다 바르게 기억해서 써요(베개, 깨끗이). |
| 된소리 | '할게', '할지'는 [할께], [할찌]로 소리 나도 'ㄲ, ㅉ'이 아니라 'ㄱ, ㅈ'으로 써요. |
| 문장 부호 | 묻는 문장 끝에는 물음표(?), 설명하는 문장 끝에는 마침표(.), 느낌이 큰 문장 끝에는 느낌표(!)를 써요. |
| 띄어쓰기 기초 | 낱말과 낱말 사이는 띄어 쓰고, '은, 는, 이, 가, 을, 를'은 앞말에 붙여 써요. |

## 8. 확인 기준 (1단계 마을 완성)

- 단계 선택에서 1단계 마을이 "준비 중" 없이 열리고, 스테이지 3개를 차례로 깰 수 있다.
- 1단계 몬스터 6종이 그림으로 나오고 도감에 등록된다.
- 검수한 1단계 문제가 60개 이상이고, `npm run validate`가 통과한다.
- 4가지 화면 크기에서 1단계 문장 카드가 넘치지 않고, 3단계보다 글자가 크다.
- 3단계 플레이(수치, 문제, 기록)는 바뀌지 않는다(기존 테스트 그대로 통과).
