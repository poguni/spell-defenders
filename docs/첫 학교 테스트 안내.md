# 첫 학교 테스트 안내

> 작성일: 2026-10-10 · 대상: 5학년 우리 반 · 시간: 10~15분 · 기준: 기획서 2.4, 12.1
> 목적: 학생이 **설명 없이** 시작할 수 있는지, 어디서 막히는지, 글씨와 속도가 알맞은지 확인합니다. 학습 효과 측정(사전·사후 평가)은 본 파일럿에서 합니다.

## 준비 (테스트 전날까지)

| 할 일 | 확인 |
|---|---|
| 배포 주소를 교사 디벗에서 열어 3단계 스테이지 1을 끝까지 해 보기: https://poguni.github.io/spell-defenders/ | ☐ |
| 학생 디벗 한 대로 같은 주소 접속 확인(학교 와이파이에서 첫 화면이 뜨는 시간도 보기) | ☐ |
| 주소를 QR이나 짧은 글로 칠판에 띄울 준비 | ☐ |
| 효과음: 이어폰을 쓸지, 처음에 "소리 끄기"를 누르게 할지 정하기 | ☐ |
| 공용 디벗이면 끝난 뒤 "내 기록 지우기"를 누르게 할지 정하기 | ☐ |
| 아래 관찰 기록표 인쇄 | ☐ |

## 진행 순서 (약 15분)

| 시간 | 할 일 | 교사 말 (예시) |
|---|---|---|
| 0~2분 | 주소 접속, "전체 화면" 누르기 | "칠판의 주소로 들어가서 '전체 화면'을 눌러 보세요. 오늘은 새 게임을 시험해 보는 날이에요." |
| 2~3분 | **설명 없이** 시작하게 두기 | "어떻게 하는지는 일부러 알려 주지 않을게요. 스스로 해 보세요." |
| 3~10분 | 스테이지 1 플레이(약 3~5분) → 결과 → 낙서 지우기 | 질문이 오면 바로 답하지 말고 "화면에 뭐라고 쓰여 있어?"로 되묻기. 막힌 학생 수와 화면을 기록 |
| 10~12분 | 여유 있는 학생: 스테이지 2, 오답 노트, 몬스터 도감 둘러보기 | "지도에서 다른 것도 눌러 보세요." |
| 12~15분 | 질문 3개(아래)와 손들기 | |

## 관찰할 점

1. **설명 없이 시작하는가**: 단계 선택 → 출발 → 스테이지 1까지 혼자 가는지. 몬스터를 눌러야 한다는 것을 아는지
2. **막히는 화면**: 틀린 낱말 찾기(낱말을 눌러야 하는 것), 띄어쓰기 칼(글자 사이를 눌러야 하는 것), "고칠 곳 없음" 버튼을 알아채는지
3. **글씨 크기**: 문장 카드와 보기 글씨를 읽는 데 어려움이 없는지(얼굴을 화면에 가까이 대는 학생이 있는지)
4. **속도**: 몬스터가 너무 빨라 성에 닿는 경우가 많은지, 반대로 지루해하는지. "느리게"를 누르는 학생이 있는지
5. **설명 읽기**: 틀렸을 때 나오는 설명을 읽는지, 바로 "계속하기"를 누르는지
6. **기술 문제**: 접속이 느리거나 그림이 늦게 뜨는지, 화면이 잘리는지, 소리 문제

## 학생에게 물어볼 질문 3개

1. 처음에 무엇을 해야 하는지 바로 알았나요? 헷갈린 곳이 있었다면 어디였나요?
2. 몬스터 빠르기는 어땠나요? (너무 빠름 / 알맞음 / 너무 느림 — 손들기)
3. 이 게임으로 맞춤법을 또 연습하고 싶나요? 바꾸고 싶은 점이 있나요?
